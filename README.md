# Terminal ARPG

以 Build 規劃、自動刷圖、打寶成長與戰鬥終端為核心的文字放置 ARPG。

## Alpha 0.12

- 戰鬥逐隻處理索敵、移動、攻擊、受傷、死亡與再次索敵
- 64×40 格迷霧地圖、12 個房間與走道、隨機怪物座標
- HP、MP、藥劑充能及每次技能傷害共用同一戰鬥狀態
- 六顆主動技能改用 PoEDB 可確認名稱、Lv.1 數值與新手底材
- 新手區使用 PoE 等級 1 至 3 怪物基礎生命、傷害與稀有度生命倍率
- 移除無來源的技能等級每級 6% 展示加成
- 舊存檔自動遷移至來源已校正的新手武器

- PoEDB 可查證的 14 組 NPC 小通貨固定兌換
- 支援單次兌換與依錢包餘額全換
- 混沌石與更高階通貨排除於 NPC 直接購買表

- 31 種核心通貨共用資料表、無上限錢包與地圖掉落池
- 17 種現有裝備系統可承接的 PoE 式通貨效果
- 遊戲內公開顯示通貨掉落等級、相對權重與滿池抽選率

- 從等級 1、磨損武器與單一技能開始
- 六段短篇行動逐步解鎖裝備、技能、材料與 T1 地圖
- Build 藍圖顯示目前進度與下一個目標
- 按張數、時間或地圖耗盡持續刷圖
- 玩家指定 T1 至 T5 的固定階級連刷與跨 Tier 地圖掉落
- 每張地圖 400 至 600 隻場上怪、18 至 26 個混合怪群與末端唯一首領
- 240 格迷霧地圖與逐區探索
- 主動技能標籤、輔助條件、洞色與連線共同決定寶石是否生效
- 技能與輔助必須先取得，再明確插入同一件已裝備物品
- 每張成功地圖產生多件裝備、寶石、通貨與地圖圖印
- Build 感知裝備排序，顯示 DPS、清圖或生存差異
- 關閉、普通與智慧三種自動分解設定
- 分解材料可校準裝備詞綴
- 瀏覽器本機永久存檔
- 100 件固定背包上限、三頁可命名倉庫與裝備篩選器
- 倉庫標價、上架鎖定、取消與通貨購買流程
- 通貨防呆與舊存檔失聯裝備自動修復
- 固定 seed 的可重播遊戲核心

## 開發與驗證

```bash
npm install
npm run dev
npm test
npm run lint
npm run build
```

公開版本需完成三種停止模式、換裝、技能重評分、自動分解、材料消耗、存檔重載與手機版回歸。

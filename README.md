# Terminal ARPG

以 Build 規劃、自動刷圖、打寶成長與戰鬥終端為核心的文字放置 ARPG。

## Alpha 0.21

- 交戰中的整個怪群會依各自稀有度速度逐格逼近玩家，地圖上的怪物位置會真實變化
- 每隻近身怪物擁有獨立攻擊時鐘，多隻怪物能同時形成包圍與生命壓力
- 小地圖新增紅色怪物攻擊線、追擊狀態與怪群推進訊號
- 新增固定版本檢討、五項玩法評分與主軸追蹤紀錄，未達 7/10 持續開發

## Alpha 0.20

- 每隻存活怪物各自使用一個小地圖標記，依普通、魔法、稀有、特殊與首領分色，受攻擊目標會放大閃爍
- 盜賊、魔法師、服事的起始技能改為 Allflame 熱門技能：旋風斬．騷動、冬季之球、贖罪烙印
- 小地圖依技能形態呈現旋轉範圍、冰球投射落點、烙印連線與 20 層能量爆炸
- 地圖下方獨立統計裝備掉落、拾取、分解、留地、通貨與寶石；掉落圖示不進入小地圖

## Alpha 0.19

- 選職後直接進入永久開放的完整 T1，取消新手區域、任務與保證裝備
- 每張 T1 維持 400 至 600 隻怪，裝備部位、底材、技能寶石與通貨都由隨機掉落決定
- 移除青色歷史軌跡，角色標記依實際路徑逐格移動，移動時間由即時移動速度決定
- 地圖角色以線性位移呈現，投射物、受傷閃爍、迷霧探索與暫停續跑保留
- 新技能只有實際掉落後才進入背包與比較提示

## Alpha 0.18

- 怪群會實際生成在同一位置，毒蛇鞭笞、電弧與範圍技能依 PoEDB 效果命中多個同群目標
- 遠程技能會在距離外停下並顯示投射路徑，近戰仍須接近怪物
- 地圖保存受擊閃爍與交戰動畫，預設 150% 並可縮放至 100% 至 250%
- 戰鬥中出現裝備升級提示，可立即換裝並看到 DPS、生命與護甲變化
- 正式地圖維持 400 至 600 隻怪

## Alpha 0.17

- 怪物死亡時立即結算經驗，不再等整張地圖完成
- 魔法、稀有、特殊與首領怪會在實際死亡時把裝備及通貨送入玩家帳戶
- 地圖結束只做結果核對，避免獎勵重複入帳
- 新增強制公開版本壓力門檻：5,000 圖、1,000 組逐殺守恆、1,000 圖長期養成及手機實玩流程

## Alpha 0.16

- Lv.1 六圍皆為 1，可用能力點改為 0；升級後依 RO 公式取得能力點
- 新增 RO 式能力與衍生屬性面板：ATK、MATK、DEF、MDEF、HIT、FLEE、CRITICAL、ASPD
- 能力點可隨時全部重置，配點與裝備會即時重算面板及進行中的戰鬥能力
- 舊版 48 點存檔自動轉換，不影響角色、裝備與進度

## Alpha 0.15

- 移除頁首通貨累積列，通貨集中在打造、商人、交易與掉落紀錄中
- 移除舊火炬天賦，改為 RO 的 STR、AGI、VIT、INT、DEX、LUK 能力配點
- 舊版曾於 Lv.1 提供 48 點，已由 Alpha 0.16 的從零成長規則取代
- 六圍直接影響近戰、遠程、法術、攻速、施法速度、生命、魔力與暴擊
- 舊存檔保留角色、裝備與進度，舊天賦停止生效並轉為未配置六圍

## Alpha 0.14

- 魔力不足時依 PoE 普通攻擊邏輯改用武器攻擊，魔力回復至技能消耗後自動切回技能
- 暫停會保存當前位置、迷霧、怪物生命、角色資源與擊殺進度，按「繼續」接續同一張圖
- 縮小終端時間與訊息標籤，主要動作依種類使用獨立色彩
- 普通攻擊資料基準：玻璃利片、朽木法杖、朽木之棒的武器傷害、攻速與暴擊率

## Alpha 0.13

- 天賦改用 TLIDB 可查證的巨力之神、狩獵之神與知識之神數值
- 攻擊傷害與法術傷害只套用至相符技能標籤
- 最大魔力與技能消耗正式進入同一戰鬥狀態
- 無來源的職業、二轉與昇華戰力加成暫停進入計算

- 戰鬥逐隻處理索敵、移動、攻擊、受傷、死亡與再次索敵
- 64×40 格迷霧地圖、12 個房間與走道、隨機怪物座標
- HP、MP、藥劑充能及每次技能傷害共用同一戰鬥狀態
- 六顆主動技能改用 PoEDB 可確認名稱、Lv.1 數值與新手底材
- 新手區使用 PoE 等級 1 至 3 怪物基礎生命、傷害與稀有度生命倍率
- 移除無來源的技能等級每級 6% 展示加成
- 舊存檔自動遷移至來源已校正的新手武器

- PoEDB 可查證的 14 組 NPC 小通貨固定兌換
- 支援單次兌換與依錢包餘額全換
- 混沌石與更高階通貨排除於 NPC 直接購買表

- 31 種核心通貨共用資料表、無上限錢包與地圖掉落池
- 17 種現有裝備系統可承接的 PoE 式通貨效果
- 遊戲內公開顯示通貨掉落等級、相對權重與滿池抽選率

- 從等級 1、磨損武器與單一技能開始
- T1 從建立角色後永久開放，裝備、技能與材料由掉落取得
- Build 藍圖顯示目前進度與下一個目標
- 按張數、時間或地圖耗盡持續刷圖
- 玩家指定 T1 至 T5 的固定階級連刷與跨 Tier 地圖掉落
- 每張地圖 400 至 600 隻場上怪、18 至 26 個混合怪群與末端唯一首領
- 240 格迷霧地圖與逐區探索
- 主動技能標籤、輔助條件、洞色與連線共同決定寶石是否生效
- 技能與輔助必須先取得，再明確插入同一件已裝備物品
- 每張成功地圖產生多件裝備、寶石、通貨與地圖圖印
- Build 感知裝備排序，顯示 DPS、清圖或生存差異
- 關閉、普通與智慧三種自動分解設定
- 分解材料可校準裝備詞綴
- 瀏覽器本機永久存檔
- 100 件固定背包上限、三頁可命名倉庫與裝備篩選器
- 倉庫標價、上架鎖定、取消與通貨購買流程
- 通貨防呆與舊存檔失聯裝備自動修復
- 固定 seed 的可重播遊戲核心

## 開發與驗證

```bash
npm install
npm run dev
npm test
npm run lint
npm run build
```

公開版本需完成三種停止模式、換裝、技能重評分、自動分解、材料消耗、存檔重載與手機版回歸。

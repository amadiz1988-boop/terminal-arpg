# RO 怪物重生來源核對

固定來源版本見 `game/ro/source.ts`。

| 規則                | 固定來源                                                                    | 實作                                                                                                         |
| ------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `prt_fild08` 生成組 | `rAthena/npc/re/mobs/fields/prontera.txt` 第 94 至 114 行                   | 五種怪物、21 組生成資料、總數 271，座標、範圍、數量與延遲逐欄保存                                            |
| 重生計時            | `rAthena/src/map/mob.cpp` 的 `mob_setdelayspawn`                            | `delay1 + rnd() % delay2`，最低 1 秒，再套用怪物類型倍率；目前來源未填 `delay2`，所以本圖採固定 5、10、15 秒 |
| 區域落點            | `rAthena/src/map/mob.cpp` 的 `mob_spawn` 與 `map_search_freecell`           | 先在生成區域嘗試 8 次；中心可走時允許回退中心；中心不可走時再全圖嘗試 50 次                                  |
| 全圖生成邊界        | `rAthena/src/map/map.cpp` 的 `map_search_freecell`、`conf/battle/misc.conf` | 全圖生成排除地圖邊緣 15 格；區域生成按 `xs - 1`、`ys - 1` 取點                                               |
| 玩家附近限制        | `rAthena/conf/battle/monster.conf`                                          | `no_spawn_on_player: 0`，因此目前不加入避開玩家的自訂限制                                                    |
| 暫停掛機            | 專案既定多人世界規則                                                        | 只停止玩家 OpenKore 行動；共享世界時鐘、怪物巡走、攻擊與重生繼續                                             |

## 本輪修正

- Lunatic 四組範圍恢復為 `30x30`、`50x50`、`50x50`、`50x50`。
- Fabre 三組範圍恢復為 `70x70`、`70x70`、`90x90`。
- 移除「重生不能與其他怪物同格」的自訂規則。
- 移除自訂 200 次取點，改用來源定義的 8 次區域取點與 50 次全圖回退。

# Alpha 0.5 實玩驗收

測試日期：2026-09-05

## 結論

Friends Alpha 的 30 分鐘循環評分為 **7.2 / 10**。這代表目前版本可以交給朋友測核心循環，仍未達到完整 ARPG 的內容深度。

## 加速長時測試

固定種子 `824` 連續模擬 45 張地圖，每張以 42 秒設計時間換算，共 31.5 分鐘等價遊玩。

| 指標 | 結果 |
| --- | ---: |
| 完成地圖 | 45 |
| 成功 / 死亡 | 42 / 3 |
| 可感知決策 | 30 |
| 裝備升級 | 20 |
| 追獵結算 | 10 |
| 策略切換 | 4 |
| 最長無獎勵區間 | 5 張 |
| 材料消耗 | 25 |
| 資源鎖死 | 0 次 |

機械閘門得到 10 分，只代表所有程式化門檻通過。人工評分仍依內容量與實際操作扣分。

## 真實介面實玩

使用 390 × 844 手機視窗與桌面視窗操作：

1. 檢查從零開始的任務指引、初始武器、技能鎖定與 Build 藍圖。
2. 實跑兩輪各 5 張地圖，驗證自動連刷、停止條件與完整事件紀錄。
3. 切換刷圖產業，四次成功後正確出現三選一武器，選項顯示目前 Build 的提升百分比。
4. 驗證 T2 固定連刷。測試中先發現 T1 耗盡後會意外跳到 T5，已修正為只消耗玩家指定的 Tier。
5. 驗證裝備升級排序、智慧分解說明、專精點、製裝材料與追獵進度。
6. 手機版將地圖、策略、契約、產業與連刷條件排在戰鬥終端之前，單手可以完成開刷設定。

## 已知缺口

* PoE 式 Base、Increased、More、轉換、命中、抗性與規則鉤子已有架構文件，現行 Alpha 仍只實作其中的簡化子集。
* 目前只有兩個裝備欄、三個技能與三條刷圖產業。
* 拍賣場、完整打造、分板天賦、首領邀請、賽季經濟尚未完成。
* 朋友測試資料存在各自瀏覽器，尚未提供帳號與雲端存檔。

下一階段應先完成完整 Modifier Engine 與分板天賦，再擴充拍賣場。這個順序可避免介面先綁死錯誤公式。

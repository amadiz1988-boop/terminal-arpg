# 開發檢討與主軸追蹤

## 完成條件

遊戲只有同時符合下列條件才標記為「好玩版本」：

1. 加速實玩涵蓋至少 30 分鐘等效時間。
2. 打怪割草、打寶、養成、打造、流派構築五項各自留下可重現證據。
3. 綜合自評達 7.0/10，且不存在任何低於 5.0/10 的核心項目。
4. `npm run test:release` 輸出 `RELEASE_GATE_PASS`。
5. 公開站再次通過完整玩家流程。

## 固定檢討格式

每次版本更新都記錄：版本、主軸缺口、玩家可感知改動、30 分鐘等效實玩結果、五項分數、測試證據、未解風險、下一個最高優先工作。未達 7.0/10 時只能標示「持續開發」。

## Alpha 0.20 檢討

- 證據：角色逐格移動、每隻怪物各自顯示、三種起始技能有不同地圖形態。
- 核心缺口：怪物固定原地，只有當前目標定時反擊，怪群沒有追擊、包圍及群體傷害壓力。
- 結論：地圖已可觀看，交戰仍缺乏敵我雙向互動，綜合 4.5/10。
- 下一步：把怪群移動與獨立攻擊時鐘加入逐幀戰鬥狀態機。

## Alpha 0.21 檢討

- 玩家可感知改動：交戰中的整群怪物會逐格逼近；每隻近身怪物依自身時鐘攻擊；地圖以紅色攻擊線、受傷閃爍與怪群推進訊息呈現壓力。
- 來源：見 `docs/MONSTER_AI_SOURCE_AUDIT.md`。
- 31.5 分鐘等效實玩：45 圖、成功 43、死亡 2、58 次決策、24 次換裝、43 顆寶石、725 個通貨、12 次通貨消耗、14 次地圖兌換、零鎖死。
- 成長結果：DPS 21 → 57，提升 171%；最長連續無獎勵 2 圖。
- 自評：打怪割草提升至 6.0，怪群有實際追擊與包圍感；打寶、養成、打造與流派構築沒有同步提升，綜合 5.0/10。
- 未解風險：怪物仍共用近戰原型，尚未形成遠程、衝鋒、施法與首領技能差異；掉落決策密度仍低。
- 下一步：完成可查證的 T1 怪物原型配對，再提高裝備掉落的決策密度。

## 不偏離主軸規則

2026-09-09 起，PoE 與火炬方向已由使用者取消。Alpha 0.21 分數只保留為歷史，不能作為 RO 版本的完成證據。

RO 版本工作優先序固定為：可行走地圖 → OpenKore AI 佇列 → 真實逐擊戰鬥 → 掉落與拾取 → 補給與死亡復原 → 能力與技能成長 → 轉職與地圖進程。純裝飾、結算式假戰鬥及來源不明內容不得插隊。

## RO Pivot R0 檢討

- 主軸缺口：現有產品仍是 ARPG 地圖與 PoE 式物品系統，無法符合 RO 純掛機目標。
- 本次決策：鎖定 rAthena Renewal 與 OpenKore commit，撤銷尚未發布的 Alpha 0.22 戰利品決策改動。
- 分數歸零原因：新的核心循環尚未形成，舊版遊玩結果不具可比性。
- 下一步：建立初心者、波利地圖、逐格尋路、索敵、普通攻擊、受傷、死亡、掉落與拾取的單一可回放切片。

## RO Core R0.1 檢討

- 玩家可感知改動：尚未接上前端，無法由公開網站感知。
- 無介面世界：讀取 OpenKore `prt_fild08` 400×400 FLD2；依 rAthena 六組出生資料建立 87 隻波利。
- 30 分鐘等效測試：種子 824，持續運作 1,800,000ms，擊殺 208，Base EXP 31,200，剩餘 HP 31，事件 4,451；拾取 Jellopy 150、Apple 26、Wing_Of_Fly 7、Sticky_Mucus 7。
- 因果檢查：每次移動一格；掉落必須跟隨死亡；拾取必須跟隨地面掉落；分段 30 秒續跑結果等於連續 60 秒。
- 自評：底層首次形成可回放循環，怪物仍未移動，介面尚未呈現，沒有技能、裝備決策與職業成長，綜合 1.0/10。
- 下一步：加入波利漫遊、受擊反應與追擊，接著把同一份世界狀態顯示在小地圖與戰鬥終端。

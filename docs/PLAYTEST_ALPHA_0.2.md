# Alpha 0.2 實玩評估

## 已成立

- 六段引導能從新手武器帶到第一套可刷圖 Build。
- 連續刷圖、地圖消耗、裝備比較、自動分解形成基本閉環。
- 切換技能與裝備會立即改變 DPS、清圖及生存評分。

## 核心缺點

1. 引導完成後，Build 藍圖停在 6/6，缺少下一個可追逐目標。
2. 刷圖前只有效率策略，缺少可感知的風險與報酬抉擇。
3. 角色成長主要來自隨機裝備，玩家無法主動塑造長期方向。
4. 高階地圖沒有失敗壓力，生存屬性的重要性偏低。

## Alpha 0.3 對應改進

- 三種地圖契約提供不同風險、通貨、裝備等級與地圖升階機率。
- 介面在執行前顯示目前 Build 的失敗風險。
- 地圖可能失敗，失敗仍保留少量經驗，且不產出戰利品。
- 每兩級取得一點專精，可投入毀滅、疾行或壁壘，形成主動成長路線。

## 尚未解決

- 裝備欄位仍只有武器與護甲。
- 技能尚無輔助技能連結與多技能協同。
- Build 藍圖尚未延伸至進階與終局階段。
- 朋友進度仍儲存在各自瀏覽器，尚無跨裝置帳號。

# RO 職業與戰鬥終端設計基準

更新日期：2026-09-12

## 產品決策

遊戲規則採 rAthena Renewal，角色移動、索敵、戰鬥、拾取、補給、死亡復原與終端行為採 OpenKore 可查證能力。玩家在創角時選定一轉志願，仍以初心者身分完成 Renewal 新生流程，之後由伺服器正式執行一轉。

## 轉職門檻

門檻以鎖定版本 rAthena Job Master 設定為伺服器裁定：

| 路線 | Base Lv. | Job Lv. |
| --- | ---: | ---: |
| 標準二轉與跆拳分支 | 1 | 40 |
| 忍者、神槍手擴充二轉 | 99 | 70 |
| 擴充超級初心者 | 99 | 99 |

未達門檻時只顯示缺少的條件，不發放試煉書，也不建立試煉地圖。已完成轉職的角色將該分支標記為完成，無法重複領取獎勵。

## 二轉試煉

1. 玩家在任務日誌雙擊自己的二轉分支。
2. 伺服器重新讀取職業、性別、Base／Job 等級與任務狀態。
3. 符合條件後顯示確認視窗，發放重量 0 且不可掉落、交易、販售、倉庫、郵件與拍賣的試煉書。
4. 建立以 `lhz_dun_n` 為地形基礎的私人 instance，介面名稱顯示「二轉試煉之地」。
5. 試煉怪物保留原始外觀與顯示名稱，使用專用弱化資料與專用掉落規則。每次擊殺由伺服器事件累積一枚二轉黨證。
6. 累積 100 枚後標記試煉完成並傳送至二轉學院。斷線或死亡時依任務狀態恢復，不重複發證或重複建立獎勵。
7. 二轉學院 NPC 以道具 ID 與角色變數原子驗證試煉書及 100 枚黨證，成功後一次消耗、轉職、發放職業武器並傳送南門。

## 終端資訊架構

1. 角色資訊：HP、SP、Base／Job 等級、經驗、負重、Zeny 與職業。
2. 探索地圖：玩家、可見怪物、其他玩家、傳點與目前路徑。
3. 戰鬥終端：尋路、鎖定、逐擊傷害、受傷、暴擊、掉落、拾取、經驗與死亡。
4. 任務日誌：時間戳、NPC 對話、目標地圖、任務需求、目前進度與下一步。
5. 對話欄：一般、密語、隊伍、公會、家族、戰場、地圖與交易頻道。

戰鬥資料與任務資料各自保留來源與事件序號，玩家可在任務執行時同時查看任務黑窗與戰鬥終端。

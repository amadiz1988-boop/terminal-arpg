## Source implementation and safety

`src/map/pc.cpp::pc_setpos` and `pc_setsavepoint` are relocation and save-point authority. `sql-files/main.sql::char.save_map/save_x/save_y` persists the existing save point, so `NEW_STORAGE_REQUIRED=NO`. `char_reg_num[world_teleport_available_at]` is one per-character cooldown authority. A rejected relocation before confirmation does not commit cooldown or spend Zeny; confirmation failure triggers a best-effort position, cooldown and Zeny rollback. Same-map is `ALREADY_ON_TARGET_MAP`. Field to town is free with no cooldown read/write. Town to town sets +30 seconds. Town or field to farm sets +60 seconds and, from Base Lv.67, pays destination normal-monster minimum level ×10 Zeny. Base Lv.66 and below are free. Native repeats map/spawn/level/landing/Zeny/cooldown checks; the Web index is preflight only.

Source catalog uses active rAthena spawn evidence, `db/re/mob_db.yml`, the shared resource classifier extracted to `scripts/lib/ro-yaml-records.mjs` and map cache. Quest-script evidence on a source-only map, or on a shared dungeon spawn source, remains `QUEST_ACCESS_REVIEW_REQUIRED`. The static index is generated by `scripts/build-world-map-teleport-source.mjs`. It is not a navigation-route allowlist.

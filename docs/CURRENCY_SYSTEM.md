# 通貨系統基準

## 合規狀態

目前通貨名稱與主要用途為 `原作可確認`。Alpha 掉落權重為 `分析推導／待使用者核准`，不得視為 PoE 原始設定或後續正式經濟基準。核准流程依 `DESIGN_SOURCE_POLICY.md` 執行。

## 證據界線

- PoEDB 可確認通貨名稱、用途、堆疊數量與部分掉落等級：https://poedb.tw/tw/Stackable_Currency
- Grinding Gear Games 沒有公開一般怪物的伺服器端通貨掉落權重，因此無法照搬 PoE 真實權重。
- 下表 `Alpha 權重` 是鬼島傳說可測試、可版本化的相對抽選值。抽到率為該權重除以當前物品等級可掉落項目的權重總和。
- PoEDB 列出的 200 個可堆疊項目含碎片、聯盟專用貨幣、舊系統物件與機制道具。Alpha 0.9 開放 31 種一般地圖核心通貨，其餘項目等相依玩法存在時加入對應掉落池。

## 掉落計算

每張成功地圖先依怪物組成計算通貨抽選次數：

```text
抽選基數 = 普通怪×0.004 + 魔法怪×0.025 + 稀有怪×0.09 + 特殊怪×3 + 4
通貨路線 = 抽選基數×1.45
其他路線 = 抽選基數×1.00
```

結果四捨五入，且成功地圖至少有 8 次通貨抽選。稀有與特殊怪對通貨產量的貢獻明顯高於普通怪。

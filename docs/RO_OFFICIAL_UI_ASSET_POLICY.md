# RO 官方 UI 素材使用規範

## 強制原則

1. 官方客戶端已有對應素材時，玩家介面直接使用該素材，不以 CSS 重畫外觀。
2. BMP 只進行透明背景與網頁格式轉換，保留原始像素、尺寸及按下狀態。
3. 視窗採官方九宮格，按鈕採 A／B 狀態，核取方塊與單選框採官方 Default Skin。
4. 每個素材記錄來源檔、輸出檔與 SHA-256；無來源素材不得標示為官方。
5. 官方素材缺件時顯示明確的待補狀態，不以錯誤職業或錯誤物品圖示冒充。
6. 每次套用後以 390×844 手機與桌面玩家頁操作，檢查尺寸、按下狀態、文字、載入失敗及瀏覽器錯誤。

## 已確認素材來源

- `C:\Program Files (x86)\Gravity\RagnarokOnline\skin\default`：101 個官方 BMP。
- `data.grf`：道具圖示、卡片圖示、音效與介面資源。
- `data0.grf`：角色 ACT／SPR、地圖 GAT／RSW 與介面資源。
- `BGM`：官方音樂檔。
- `.local/ro-stack/openkore/tables/twRO/items.txt`：OpenKore 台灣伺服器繁中物品名稱表。
- 官方客戶端 `System/iteminfo_new.lub`：物品顯示名稱與資源鍵的第二來源。

使用者已於 2026-09-10 聲明已取得本機官方客戶端內容使用授權。

## 現行套用範圍

- 已直接套用：登入確認、創角確認、角色選擇確認／取消、聊天傳送、NPC 下一步／關閉、返回掛機、核取方塊、單選框及視窗背景。
- 已匯入：Default Skin 101 個 BMP、42 種透明道具／卡片圖示、紙娃娃、地圖與音樂素材。
- 待完成：所有功能視窗的九宮格邊框、分頁按下狀態、捲軸、裝備槽、技能按鈕與系統按鈕全面替換。
- 已知缺件：`N_Main_Gauche` 與 `N_Battle_Axe` 的專用圖示尚未定位；盜賊新手短劍使用官方共用 `Knife_` 資源，商人專用戰斧維持缺件狀態。

## 繁中名稱閘門

1. 玩家頁物品名稱先依 item ID 查詢 OpenKore `twRO/items.txt`，資料不存在時才採用資料庫名稱。
2. 新生訓練所有獎勵 item ID 必須存在繁中名稱；缺件、純英文或 `道具 #ID` 一律使發布測試失敗。
3. `npm run test:item-localization` 固定檢查新手藥水、現行一轉職業獎勵、防具、帽子與任務物品，並確認背包、裝備、即時背包合併及查詢輸出都經過同一轉譯函式。
4. 390×844 玩家頁測試同時檢查名稱、圖示 HTTP 狀態、瀏覽器錯誤及橫向溢位。

「全面使用官方素材」是持續執行的強制規範；完成狀態須以逐視窗玩家介面驗收為準。

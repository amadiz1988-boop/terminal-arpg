# 隨機刷寶核心

核准日期：2026-09-07

## 玩家起點

- 建立角色時只取得職業對應的起始武器與一顆已插入技能寶石。
- 選職後直接進入永久開放的完整 T1。
- 不設新手區域、教學任務、保證裝備或保證 Build 組件。

## 掉落與成長

- 裝備部位、底材、洞色、連線、詞綴、技能寶石、輔助寶石與通貨由地圖掉落決定。
- 玩家依當下實際取得的內容調整技能、裝備與配點。
- 沒有適用升級時，持續刷圖累積下一次掉落機會與打造通貨。
- 底材可以自行打造、存入倉庫、上架出售或向其他玩家購買。多人交易在帳號與伺服器持久化完成後接通。

## 地圖移動

- 角色沿尋路結果逐格前進，每一格都會更新角色座標並揭露迷霧。
- 基礎每格時間為 250 毫秒，實際時間依即時移動速度等比例縮短，最低 60 毫秒。
- 地圖以單一角色標記在座標間線性移動，不顯示歷史軌跡線。
- 暫停會保留角色座標、路徑、迷霧、怪物生命與戰鬥資源。

這份規則來自使用者明確核准，屬於本作操作與流程設計，不宣稱為 Path of Exile 或火炬之光：無限的原始設定。

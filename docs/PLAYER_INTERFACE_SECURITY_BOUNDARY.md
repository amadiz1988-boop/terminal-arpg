# 玩家介面安全邊界

## 不可變鐵律

玩家端是不受信任的顯示與輸入裝置。瀏覽器只接收角色可見資訊，並送出產品明確提供的白名單操作。伺服器永遠重新驗證帳號、角色、權限、距離、狀態、成本、冷卻與結果。

玩家介面永不接受或轉送下列內容：

- 原始 OpenKore 命令、rAthena `@`／`#` 管理指令、封包、SQL、程式碼或檔案路徑。
- 玩家提供的 action 名稱、資料欄位、物品效果、技能效果或管理權限。
- 可指定其他帳號、角色、程序、資料表、伺服器位址或內部連接埠的參數。
- 對話內容不得被送入 OpenKore 命令解析器。一般聊天直接呼叫 `sendChat()`，表情只接受固定編號後呼叫 `sendEmotion()`。

## 唯一允許的操作模型

```text
固定 UI 控制項
→ 固定 API 路由
→ 固定 action 白名單
→ 強型別及範圍驗證
→ Session 所屬帳號與角色
→ 每帳號序列化佇列
→ OpenKore／rAthena 權威驗證
→ 安全化結果回傳
```

- 前端不能決定經驗、物品、能力值、座標、傷害、Zeny、權限或執行結果。
- 伺服器不能因前端隱藏按鈕而假定操作安全；每個請求均獨立驗證。
- 玩家可見字串一律用 `textContent` 或等價安全文字節點輸出，不把角色名、物品名、LOG 或錯誤字串當成 HTML。
- 狀態變更路由拒絕跨站瀏覽器請求；Session Cookie 使用 `HttpOnly`、`SameSite=Lax`，HTTPS 入口加上 `Secure`。
- 回應套用 CSP、禁止 iframe、禁止 MIME 猜測、禁止 Referrer、限制瀏覽器權限。
- 未知伺服器例外只寫入本機紀錄；玩家端只收到通用錯誤，避免洩漏 SQL、路徑、程序與服務資訊。

## 網路與拓樸保密

- 玩家 API 只公開「世界正常／無法連線」及玩家需要的遊戲資料。
- 玩家 API 不回傳資料庫、登入、角色、地圖服務名稱、內部 IP、主機名、連接埠、程序 ID、檔案路徑或錯誤堆疊。
- 完整健康檢查只允許本機回環位址呼叫，供維運腳本使用。
- 正式入口使用 HTTPS 網域與反向代理或 outbound-only tunnel；玩家 DNS 與瀏覽器不能直接連到來源主機。
- Dashboard、MariaDB、rAthena 與 OpenKore 對外服務只監聽本機回環位址；同一區網也不能繞過 Tunnel 直連玩家 API。
- 來源主機不開放 MariaDB、rAthena、OpenKore 或管理介面至公網。管理入口與玩家入口分離。
- 文件、前端程式、原始碼映射、資產清單與錯誤訊息不得寫入真實公網 IP 或內網 IP。

隱藏 IP 只能降低直接攻擊面，不能取代更新、最小權限、限流、稽核、備份與入侵監控。

## 帳號申請與阻斷服務防護

帳號登入與首次註冊共用公開端點，伺服器先完成廉價的來源限流與格式檢查，再執行資料庫查詢及 scrypt。現行控制層固定採用：

- 同一來源 IP 五分鐘最多 40 次帳號請求，輪換帳號名稱也會被限制。
- 同一帳號名稱五分鐘最多 10 次嘗試，輪換來源 IP 也會被限制。
- 同一來源 IP 一小時最多建立 8 個新帳號。
- 全站十分鐘最多建立 30 個新帳號，既有帳號登入不消耗註冊額度。
- 註冊事件只保存來源位址的 HMAC-SHA256，不保存可直接讀取的 IP；額度由 MariaDB 共用，Dashboard 重啟或多程序也不能重置或倍增限額。
- 帳號序列化佇列最多 12 筆，避免慢速密碼雜湊造成無上限記憶體堆積。
- JSON 請求本文最多 8 KiB，依實際位元組數及 `Content-Length` 雙重拒絕。
- Cloudflare 來源 IP 標頭只在本機反向代理且帶有 Cloudflare Ray 識別時採信，直接請求不能任意偽造限流身分。
- HTTP 429 回傳 `Retry-After`，前端不得自動重送註冊。

這些限制處理大量註冊、密碼猜測、慢速運算與佇列耗盡。流量型 DDoS 必須由固定 Cloudflare Tunnel、WAF、邊緣 Rate Limiting 與來源主機防火牆共同承擔；Quick Tunnel 沒有可稽核的專案級 WAF 規則，因此不能列為完整 DDoS 防護。

## 驗收清單

1. 跨來源 POST、PUT、PATCH、DELETE 收到 HTTP 403。
2. 偽造 action、額外欄位、他人角色 ID、原始命令與管理指令均不能執行。
3. 公開 `/api/health` 不含服務名稱、IP、連接埠與資料庫狀態。
4. `/api/internal/health` 從非回環來源取得 HTTP 404。
5. 玩家可見 API 與 HTML／JS 不含來源 IP、內部服務名稱、路徑或堆疊。
6. 帳號 A 無法讀取或操作帳號 B 的角色、背包、裝備、指令佇列與掛機程序。
7. 安全標頭、登入限流、Session 過期、重播防護與未知錯誤遮蔽通過自動測試。
8. 既有登入、創角、離線掛機、能力配點、道具使用與多人共享世界回歸測試通過。
9. 對話拒絕換行、控制字元、超過 80 字、未知 action 及未列入白名單的表情編號；玩家輸入的 `@`、`#` 或 OpenKore 命令文字只能成為普通聊天內容。
10. 輪換帳號名稱的來源 IP 洪水、輪換來源 IP 的單一帳號洪水及超過 8 KiB 的 JSON 均收到 HTTP 429 或 413。
11. 正式公開前以 Cloudflare 正式 Tunnel 與固定網域部署 WAF、Bot 規則及邊緣 Rate Limiting，再以外網負載測試驗收來源主機不被直連。
12. Dashboard 只監聽 `127.0.0.1`，以主機區網位址連線 8788 必須失敗；公開 Tunnel 健康檢查仍須成功。
13. 兩個獨立 Dashboard 程序必須共用相同的每來源註冊額度；第 9 次註冊仍須收到 HTTP 429，重啟不得清除尚未到期的事件。

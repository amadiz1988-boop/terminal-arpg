# 遊戲資料來源與核准制度

本文件落實根目錄 `AGENTS.md` 的來源真實性鐵律。

## 資料來源優先序

1. Path of Exile、火炬之光：無限官方公告與遊戲內說明
2. PoEDB、TLIDB 與可追溯的資料探勘資料
3. 有版本資訊、畫面證據及可重現過程的玩家測試
4. 多個獨立來源一致的社群研究
5. 專案分析推導，必須等待使用者核准

## 開發准入條件

任何內容進入 `game/content` 或正式公式前，必須通過以下檢查：

| 檢查 | 必要結果 |
|---|---|
| 名稱來源 | 有來源網址與版本 |
| 效果來源 | 原文或可驗證摘要 |
| 公式來源 | 官方公式或可重現推導 |
| 數值來源 | 可確認數值或使用者核准值 |
| 差異說明 | 清楚列出本作為配合文字放置玩法所做的調整 |
| 測試 | 驗證效果、限制條件與資源消耗 |

任一必要結果缺失時，該內容只能留在研究文件，狀態為 `待查證` 或 `待使用者核准`。

## 查無底層公式時

```text
確認官方未公開
↓
搜尋資料探勘、Wiki、影片與玩家實測
↓
建立可重現的輸入與輸出樣本
↓
提出公式候選、誤差與遊戲影響
↓
向使用者請求核准
↓
核准後才進入正式遊戲資料
```

## 現有內容稽核

Alpha 0.9 的通貨名稱與主要用途可由 PoEDB 查證。地圖掉落權重屬專案暫定推導值，PoE 官方沒有公開真實伺服器權重，因此狀態改列為 `待使用者核准`。在取得核准前不得宣稱這些權重是 PoE 設定，也不得以它們作為後續經濟平衡基準。

下一批需要稽核的資料：

1. 通貨掉落權重與掉落等級
2. 裝備詞綴階級、數值範圍與物品等級門檻
3. 洞數、顏色與連線機率
4. 技能及輔助寶石數值
5. 天賦與職業特性
6. 怪物數值與掉落倍率

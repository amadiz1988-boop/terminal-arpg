# RO 職業排行榜與公會頁計畫

## 各職業排行榜

每個一轉及後續職業提供獨立分頁，排序主鍵依序為 Base Level、Base EXP、Job Level、Job EXP，平手再依角色建立時間。公開列只顯示角色名稱、職業、Base／Job 等級、公會名稱與紙娃娃縮圖。

點擊角色後開啟唯讀公開頁，顯示：

- 紙娃娃與外觀。
- 已裝備物品、精煉、洞數與卡片。
- Base／Job 等級。
- 公會及可公開的成就。

安全與公平條件：

- 查詢固定排除 `web_account_flags.is_test=1`。
- 不回傳帳號名、角色 ID、在線狀態、座標、IP、內部服務與背包內容。
- 排行資料由 rAthena 角色、裝備與公會資料讀取，前端不提交排序值。
- 紙娃娃只使用伺服器回傳的外觀與已裝備資料。

## 公會頁

使用 rAthena 原生公會資料、邀請、成員、職位、會長、公告、經驗、技能與公會聊天。OpenKore 負責角色端封包及原生互動，網頁只建立型別化白名單操作。

第一階段：

1. 公會搜尋與公開資料。
2. 建立公會、邀請、接受、退出及踢除。
3. 成員清單、職位、會長、公告與在線可見性設定。
4. 公會頻道即時收發、封鎖、檢舉及限流。
5. 從排行榜角色頁連到公會頁。

後續階段：公會技能、公會經驗、同盟／敵對、公會倉庫、公會據點與城戰資料。

測試帳號不得建立、加入或出現在公開公會。公會管理操作必須由 rAthena 驗證會長、職位、成員狀態及冷卻限制。

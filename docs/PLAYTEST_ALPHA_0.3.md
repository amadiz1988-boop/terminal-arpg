# Alpha 0.3 五分鐘實玩評估

## 結論

評分 2/10。系統可運作，重玩動機尚未成立。

## 實測證據

- 307 秒內約 12 次有效操作。
- T3 與 T4 各刷一張便因升階停止，需重新選 Tier 並啟動。
- T5 首領懸賞失敗後，T1 至 T5 全部歸零，角色無法再次刷圖。
- 每張地圖固定重複掃描、施法、掉落、稀有怪與首領五種文字。
- 公開版記錄到兩次 React 418 顯示同步錯誤。

## Alpha 0.4 修正

- 所有地圖耗盡時提供免費邊境巡邏，恢復三張 T1。
- 選中 Tier 無庫存時自動選擇最高可用 Tier。
- 循環期間取得高階地圖會自動升階，保持連續執行。
- 玩家選擇武器、護甲或材料獵取目標，每四張保證一次目標獎勵。
- 保存亂數進度並清理重複物品識別，避免重載後重複鍵值。
- 初始終端時間固定，消除伺服器與瀏覽器時間差造成的同步錯誤。

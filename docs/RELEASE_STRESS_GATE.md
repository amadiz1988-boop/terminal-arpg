# RO 公開版本壓力與玩家流程門檻

每次公開版本都要證明玩家能從新角色開始，完成 Renewal 新生流程、實際殺怪、取得經驗、收到掉落、處理負重、補給、轉職並持續掛機。資料函式通過不等於玩家頁流程通過，兩者分開驗證。

## 固定門檻

1. 所有 RO 領域規則與回歸測試。
2. 5,000 次地圖行走與尋路結果壓力測試。
3. 1,000 組逐殺經驗、掉落、拾取與負重守恆測試。
4. 單一測試帳號 1,000 次地圖循環，驗證掛機、補給、倉庫、販售、死亡與重連。
5. 手機寬度玩家頁，從註冊、創角、性別與髮型選擇、新生任務到一轉流程。
6. 實際戰鬥、擊殺經驗、掉落入帳、裝備穿脫、技能配點與任務續跑。
7. 靜態檢查、正式建置與瀏覽器錯誤檢查。
8. 公開入口再次執行同一套玩家流程冒煙測試。

任一檢查失敗時，版本狀態標記為 `未通過發布門檻`。測試報告記錄測試數量、耗時、失敗項目與公開站驗證結果。

## 角色資料隔離

壓力測試角色固定使用測試帳號前綴，從職業排行榜、公會搜尋、公開角色頁、在線人數與統計資料排除。測試使用的管理者指令不提供給玩家 API。

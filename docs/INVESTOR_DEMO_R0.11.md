# 投資展示版 R0.11

日期：2026-09-10

## 今晚可展示的核心

這是一個真實運行的多人 RO 掛機垂直切片。戰鬥由 OpenKore 執行，地圖、怪物、經驗、掉落與角色資料由 rAthena 判定，MariaDB 保存角色進度。網頁負責帳號、角色、控制與呈現。

目前實裝：

- MariaDB、登入、角色、地圖四項服務健康狀態
- 首次輸入帳號密碼直接註冊，後續使用相同帳密登入
- 每個帳號建立一名初心者並取得獨立 Session
- 每名掛機角色使用獨立 OpenKore worker
- 多名角色同時進入同一個 rAthena 世界
- 開始、停止、重新登入與原角色進度保存
- 真實 HP、SP、Base、Job、六圍、點數、Zeny、地圖座標
- 每次攻擊、受傷、擊倒、經驗、掉落、拾取、死亡與復活終端紀錄
- 本次掛機時間、擊殺、死亡與實際拾取物統計
- 手機版底部功能列與桌面版 RO 視窗風格

## 三分鐘展示流程

1. 本機展示執行 `start-local-playable.cmd`；朋友外網測試執行 `start-friends-alpha.cmd`。
   完整操作與限制請見 `docs/FRIENDS_ALPHA_RUNBOOK.md`。
2. 開啟 `http://127.0.0.1:8788/`，確認右上角顯示「世界伺服器正常」。
3. 在掛機頁觀看角色索敵、逐次攻擊、受傷、取得經驗與拾取物品。
4. 切到能力頁，展示資料直接來自 rAthena 資料庫。
5. 切到道具頁，展示本次 OpenKore 實際拾取統計。
6. 使用三個帳號登入，展示三名角色同時在線、各自戰鬥與各自拾取。
7. 停止其中一名角色，確認另外兩名角色不受影響，再重新啟動該角色。

## 投資人可驗證的差異

畫面重新整理或關閉不會停止 OpenKore。只要本機伺服器與掛機程序仍運行，角色會持續戰鬥。網頁回來時會重新讀取最新伺服器狀態與期間成果。

## 今晚明確邊界

- Friends Alpha 目前限制每個帳號一名角色，壓力 gate 固定驗證三名玩家。
- 紙娃娃、完整背包操作、技能配點與 NPC 服務尚未串入這個真實控制層。
- 暫停會登出角色，重新開始會重新登入並繼續原資料；OpenKore 程序內部 AI 暫停尚未接到網頁。
- 公開 Sites 網址仍是前一代前端模擬版，不能當成這次真實後端成果展示。
- Cloudflare Tunnel 已安裝，玩家入口由各自帳密保護。此執行環境禁止 cloudflared 對外建立連線，因此今晚已驗證的是本機多人入口。外網連線狀態目前為 `【資料不足，無法確認】`。
- Friends Alpha 沿用 rAthena 帳號密碼欄位。測試者必須使用專用測試密碼，禁止重用其他網站密碼。

## 正式擴充順序

1. 控制層改用獨立密碼雜湊，rAthena 只接收內部憑證。
2. 控制層改用結構化增量事件，加入事件序號、去重與重連補送。
3. 每個活躍角色獨立 OpenKore worker，加入監督、限額與崩潰恢復。
4. 完整背包、裝備、能力、技能與 NPC 操作。
5. Cloudflare 正式網域、玩家驗證、管理者權限與稽核紀錄。
6. 多玩家壓力測試後再決定 worker 密度與主機規格。

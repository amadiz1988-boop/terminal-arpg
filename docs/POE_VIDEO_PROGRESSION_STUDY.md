# POE 拓荒影片研究：玩家到底在追什麼

研究日期：2026-09-05

Alpha 0.5 被退回的原因很直接：地圖用完便停擺，裝備只剩百分比比較，通貨沒有形成用途，玩家也感受不到從零養成。這份筆記用四支玩家教學影片重新檢查遊戲循環，並將結論轉成 Friends Alpha 的驗收條件。

## 研究素材

1. 台系歐巴，《POE3.29 處刑者穿刺旋風斬，最完整的拓荒教學》，14 分 26 秒。影片按章節拆解第一章至終章，另有技能輔助更換修正。
2. DS 低欸死，《POE3.26 全職業閃現、魅影射擊，慢跑重練全章節》，2 小時 57 分 36 秒。完整展示有基礎裝時的跑章節節奏。
3. Taco他口，《開季最適合的 5 個推薦流派，一般人怎麼快速累積前期通貨》，8 分 21 秒。內容同時比較拓荒流派、成形條件與開季農法。
4. 皓皓鵝，《POE3.29 赦免從 0 到 T16 拓荒流程教學》，12 分 45 秒。逐章記錄寶石、天賦、裝備、抗性、光環、工藝與地圖階級的切換時機。

## 影片裡真正有價值的部分

赦免教學沒有把「從零到 T16」濃縮成一個 DPS 進度條。第一章先補力量與敏捷，拿位移技能和快速攻擊；第二章開始點召喚傷害，嘗試取得瓦爾赦免；第三章追四連裝與圖書館寶石；第六章改開堅定並把元素抗性補到約 70 至 75；T5 尋找五連裝；T11 至 T15 再處理腰帶、混沌抗性與技能消耗。每一段都有一個眼前問題，也有一個能立即感受到的解法。

這使普通掉落也有用途。玩家會看屬性需求、洞色、連線、抗性、生命、底材與空詞綴。面板傷害較低的裝備仍能因四連、移動速度或抗性而成為升級。工藝的作用也很具體，例如補上一條召喚物傷害，或用精髓處理剛取得的白色底材。

流派推薦影片顯示另一層目標。拓荒流派的評價包含裝備依賴、傷害提升是否平滑、生存、清圖、打王、轉型成本與成形後的爽感。曼巴毒蛇打擊在核心傳奇取得前很卡，成形後「打一下死一片」；赦免前期順，後續也能平滑轉成其他召喚流派。玩家追的是一條可預期的成形路線，以及成形瞬間帶來的玩法改變。

通貨也連著下一個決定。影片裡會先累積輿圖天賦，再按開季市場選劫盜、礦點、傭兵或軍團；機體刷不動時可以改打綠門女王，市場改變時也會換農法。通貨能買核心裝、投資升值品、支撐轉型。取得通貨後，玩家立刻知道它能把哪個目標往前推。

## 我們目前為什麼無聊

Alpha 0.5 與未發布的 Alpha 0.6 都把成長壓成同一件事：DPS 上升。六個裝備欄、鍛造與階級解鎖增加了按鈕，仍缺少以下因果鏈。

| 影片中的循環 | 現有實作 | 結果 |
| --- | --- | --- |
| 缺屬性、抗性、連線或移動速度 | 大多只比較 DPS、清圖與生存百分比 | 掉落沒有故事，也沒有解題感 |
| 技能和輔助寶石逐章加入 | 主技能在任務中一次解鎖 | Build 沒有逐步成形 |
| 四連、五連會改變技能強度與選擇 | 武器只提供詞綴 | 低面板裝備沒有策略價值 |
| T1 到 T16 持續提出新生存與輸出需求 | 地圖主要用 DPS 門檻區分 | 玩家只是在等數字變大 |
| 農法產出服務交易、工藝與轉型 | 通貨只支付固定鍛造費 | 收到通貨沒有期待感 |
| 核心裝成形後改變操作或清怪方式 | 傳奇只是較高數值 | 沒有「終於成了」的瞬間 |

先前的自動化測試能證明循環不會卡死，也能證明數值有上升。它無法證明玩家覺得好玩。程式分數只能當穩定性檢查，人工從零遊玩的體感評分才決定能否送審。

## 立即採用的設計

第一項改動是技能連線。武器帶有一至四連，任務依序給氣勢、迴響、集中效應與護體。玩家在同一個主技能上選擇趕路、全面輸出、打王或生存。裝備評估必須計入連線帶來的結果，讓「詞綴較弱但多一連」成為合理升級。

接著加入三種地圖壓力：元素抗性門檻、首領單體門檻、清圖效率門檻。系統要指出失敗原因與可取得解法的來源。每個地圖階段至少有一個新問題，不能只提高敵人生命。

通貨要標示下一個實際用途。精華用來保證特定詞綴，工匠材料處理連線，稀有核心用來啟動會改變玩法的傳奇效果。農法面板同時顯示主要產物、目標裝與完成後能解決的問題。

## Friends Alpha 驗收

- 從零開始的前 15 分鐘，玩家至少完成三次可解釋的 Build 變化，其中一次來自技能連線。
- 玩家能指出正在找哪一件裝、去哪裡找、拿到後會解決什麼問題。
- 任一地圖庫存歸零後仍有清楚且有收益的回復路線。
- 每種畫面上顯示的通貨都有可立即使用的消耗點。
- 30 分鐘等價模擬只檢查斷糧、獎勵間隔與數值穩定；發佈前仍要完成手機尺寸的人工從零遊玩。
- 人工評分低於 7 分便繼續修改，不向測試者宣告完成。

# 戰鬥狀態機與來源紀錄

資料查證日期：2026-09-06

## Alpha 0.11 執行順序

每張圖建立獨立怪物清單，每隻怪物都有自己的編號、座標、稀有度與生命。執行順序為 `探索未知格 → 視野索敵 → 走到目標 → 鎖定單一怪物 → 逐次使用技能 → 扣除該怪生命與角色魔力 → 怪物反擊 → 扣除角色生命 → 單一怪物死亡 → 再次索敵`。野外怪物清除後才會前往首領房。只有首領生命歸零後，地圖結算函式才能發放裝備、寶石、通貨與經驗。角色生命歸零時停止本圖，不發放完成獎勵。

精簡終端保留路徑、索敵、每四次普通攻擊、全部暴擊、受傷、藥劑、擊殺與首領事件。完整終端顯示每次技能傷害。擊殺數、地圖迷霧、HP 與 MP 均讀取同一份戰鬥狀態。

## RO 式小地圖呈現

Alpha 0.11 使用 64×40 格地圖。每個種子生成 12 個不規則分布的區域，再以直角走道連通。這是依使用者要求製作的 RO 俯視地圖呈現規格，沒有宣稱為 RO 官方地圖公式。未走過的區域保持黑色迷霧，角色只會鎖定視野距離 3 格內的野外怪物；視野內沒有怪物時，會逐格探索最近的未知可行走格。普通、魔法、稀有、特殊與首領在已揭露區域使用不同顏色。

## 尚待來源稽核

野外怪群目前延續既有 T1 至 T5 對應等級 8、16、24、32、40 的 Alpha 分層，基礎生命與傷害取自 PoE 同等級表。此分層尚未取得使用者核准，狀態為 `待使用者核准`。公開內容只將它用於既有 Alpha 的戰鬥過程，未宣稱為 PoE 原始地圖規則。

每秒一次怪物反擊屬於 OpenKore 終端節奏的呈現規則。精確攻擊間隔需要綁定具名怪物資料，目前標記 `【資料不足，無法確認】`。後續每種怪物建立來源資料列後，移除此統一間隔。

## 驗收門檻

自動測試要求一張 400 至 600 隻怪的地圖必須經過超過 100 個狀態步驟、至少 50 次技能命中並發生怪物反擊。每個死亡編號都必須先有命中紀錄，最後死亡編號必須為 `BOSS-001`，擊殺總數必須和實際處理的怪物總數一致。另以四個不同地圖種子累積至少 30 分鐘等值戰鬥時間，結算函式不得提前執行。
